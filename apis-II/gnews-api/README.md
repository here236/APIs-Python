# GNews API

API consumption activity using Python – Fatec Carapicuíba

## Installation

**Prerequisites:** Python 3.12+ and Pip

```bash
# Clone the repository
git clone https://github.com/deyvidborges-dev/gnews-api.git

# Navigate to the project directory
cd gnews-api

# Install dependencies
pip install -e .

# Execute project
gnews-api
```
