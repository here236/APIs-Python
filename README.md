## Clonando o repositório

Para clonar o repositório junto com seus submódulos:

```bash
git clone --recurse-submodules https://github.com/here236/APIs-Python.git
````

Caso o repositório já tenha sido clonado sem os submódulos, inicialize-os com:

```bash
git submodule update --init --recursive
```

Para atualizar os submódulos de acordo com as referências definidas pelo repositório principal:

```bash
git submodule update --recursive
```
